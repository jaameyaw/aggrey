# Aggrey

Aggrey is an iMessage-based campus dining tool for Livingstone College. Students can text natural questions about menus, dining hours, and meal availability and get a quick, factual response based on current dining data.

## Features

- **Menus**: ask what's being served, e.g. "What's for lunch today?"
- **Dining hours**: check when dining locations open and close, e.g. "Is the cafeteria open right now?"
- **Meal availability**: find out whether a specific meal or item is available, e.g. "Is there a vegetarian option tonight?"
- **Fast, factual answers**: responses come straight from current dining data, so there's no guesswork.

## How it works

1. A student sends a question to Aggrey over iMessage.
2. Aggrey interprets the question and looks up the relevant information in the current dining data.
3. Aggrey replies in the same conversation with a short, direct answer.
